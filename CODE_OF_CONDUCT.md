# Code of Conduct

This project aims to maintain an open, professional, and collaborative
technical discussion environment. This code of conduct applies to all
issues, pull requests, reviews, documentation discussions, and community
interactions.

## Expected Behavior

- Respect others' time, background, and technical judgment.
- Focus on facts, reproduction steps, code, and design itself.
- Accept constructive criticism and be willing to revise opinions based
  on evidence.
- Provide actionable improvement suggestions in reviews, not emotional
  judgments.
- Be patient with new contributors and provide sufficient context whenever
  possible.

## Unacceptable Behavior

- Personal attacks, insults, harassment, discrimination, or threats.
- Publishing others' private information, credentials, keys, or internal
  data.
- Off-topic provocations, spamming, or sustained arguments.
- Knowingly misleading others to perform dangerous actions that risk
  security or stability.
- Disclosing details of unpatched sensitive security vulnerabilities in
  public threads.

## Scope

This code of conduct applies to:
- Issues, PRs, discussions, reviews, and commit messages in the repository.
- Online or offline discussions directly related to this project.
- Situations where you represent this project in external communication.

## Reporting

If you encounter behavior that violates this code of conduct:
- Do not escalate the conflict in public threads.
- Contact maintainers through the channels listed in [SUPPORT.md](SUPPORT.md).
- If the issue involves sensitive security content, report privately
  according to [SECURITY.md](SECURITY.md).

Maintainers will take appropriate action based on the situation, including
warnings, removing posts, locking discussions, or restricting collaboration
permissions.

## Maintainer Responsibility

Maintainers are responsible for:
- Maintaining discussion order and collaboration boundaries.
- Promptly addressing clear violations.
- Making decisions based on evidence, context, and scope of impact when
  handling disputes.

This code of conduct is not a legal document, but serves as the baseline
behavioral standard for project collaboration and governance.
